# Security policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting flow for this repository.
Do not open a public issue containing vulnerability details, credentials,
mailbox tokens, email contents, or deployment information.

Include the affected version or commit, the impact, and enough detail to
reproduce the problem safely.

## Deployment responsibility

Agent Mailbox is self-hosted. Operators are responsible for protecting the
master API key, restricting access to their deployment, configuring retention
appropriately, and complying with the rules that apply to email data in their
jurisdiction.
